
 Data Access

This project uses publicly available datasets:

- NASA MODIS FIRMS: wildfire ignition detections  
  https://firms.modaps.eosdis.nasa.gov/

- gridMET climate data: daily temperature and precipitation  
  https://www.climatologylab.org/gridmet.html

Due to size constraints, raw datasets are not stored in this repository.
Instructions for data acquisition are provided in the notebooks.
